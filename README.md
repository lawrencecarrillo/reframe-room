# The Reframe Room

**A calm AI-powered thinking space for people who are stuck — not because they lack information, but because they can't see the full landscape of their own situation.**

🔗 **Live Site:** [lawrencecarrillo.github.io/reframe-room](https://lawrencecarrillo.github.io/reframe-room)

---

## The Problem

People hit moments of being stuck — a decision they keep circling, a weight they can't put down — and they have nowhere to take it that isn't loaded. Friends give opinions. Therapy is a big commitment. ChatGPT gives advice. There is no neutral space to simply see your situation from more than one angle without someone pushing you toward an answer.

## The User

**Dave, 38.** Project manager, Brooklyn. Offered a promotion three weeks ago — more money, less time with his kids. He's talked to his wife, his brother, his best friend. Every conversation adds another opinion to the pile. He doesn't want more input. He wants to see the decision differently. He opens The Reframe Room at 11pm when the house is quiet.

## The Solution

The Reframe Room takes what you're sitting with and surfaces three neutral paths — no advice, no judgment, no preferred answer. You choose a path to explore more deeply, receive a warm closing thought, and if you're ready — one unexpected path appears that you hadn't considered at all.

The absence of advice is the feature, not a limitation.

---

## Features

- **Room Selection** — Choose your thinking mode: Quiet (neutral), Values (character-based), or Practical (logic-based)
- **Live Tone Read** — Claude reads your emotional temperature as you type and reflects a quiet acknowledgment
- **Clarifying Question** — One open-ended question before paths appear, skippable
- **Three Neutral Paths** — Generated by Claude, completely neutral, click to select
- **Deep-Dive** — Claude explores your chosen path with texture and honesty
- **Closing Thought** — A warm 2–3 sentence closing moment
- **The Unexpected Path** — One more path, outside the frame, fades in quietly after the closing
- **Begin Again** — Full session reset

## Tech Stack

| Layer | Technology |
|---|---|
| Frontend | Vanilla HTML, CSS, JavaScript |
| Backend | Cloudflare Workers (serverless) |
| AI | Anthropic Claude API (claude-sonnet-4-6) |
| Hosting | GitHub Pages |

**Why vanilla JS?** No framework was needed for this scope. Building without abstraction means every line is understood and intentional.

**Why Cloudflare Workers?** The API key must never touch the frontend. The Worker acts as a secure middleman — receiving requests from the browser, injecting credentials server-side, and returning Claude's response.

---

## AI Architecture

Six distinct system prompts power the session — each with a specific role and explicit constraints:

| Prompt | Role |
|---|---|
| `SYSTEM_PROMPT_TONE` | Reads emotional temperature, returns one sentence |
| `SYSTEM_PROMPT_QUESTION` | Generates one clarifying question |
| `SYSTEM_PROMPT_PATHS` | Generates three neutral reframed paths |
| `SYSTEM_PROMPT_DEEPEN` | Explores the chosen path in depth |
| `SYSTEM_PROMPT_CLOSING` | Writes a warm closing thought |
| `SYSTEM_PROMPT_UNEXPECTED` | Generates one unconventional path outside the frame |

Room modes (Quiet, Values, Practical) swap the `SYSTEM_PROMPT_PATHS` prompt while keeping all other prompts consistent.

## How to Run Locally

### Prerequisites
- A Cloudflare account (free)
- An Anthropic API key
- Node.js installed
- Wrangler CLI: `npm install -g wrangler`

### Steps

**1. Clone the repo**
```bash
git clone https://github.com/lawrencecarrillo/reframe-room.git
cd reframe-room
```

**2. Deploy the Cloudflare Worker**
```bash
npx wrangler deploy
```

**3. Add your Anthropic API key as a secret**
```bash
npx wrangler secret put ANTHROPIC_API_KEY
# Paste your key when prompted
```

**4. Update the Worker URL in index.html**
Replace the `WORKER_URL` constant with your deployed Worker URL:
```javascript
const WORKER_URL = 'https://your-worker-name.your-account.workers.dev';
```

**5. Open index.html**
Use Live Server in VS Code or any local server. The app runs entirely in the browser — no build step needed.
